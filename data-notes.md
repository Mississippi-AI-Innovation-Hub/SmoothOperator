# Data Notes

## Hub-ITS-Triage-Agent | AWS AI Innovation Hub PoC

---

## Overview

This repository does not include any real citizen data, production agency data, or personally identifiable information (PII) from ITS systems. All datasets used during the PoC are described below.

---

## Data Sources Used

### 1. Mississippi State Government Telephone Directory 2025–2026

| Field | Details |
|---|---|
| Source | Mississippi Department of Information Technology Services (ITS) — publicly available |
| Format | PDF (original); structured text (embedded in Lambda) |
| Data type | Public |
| Use | Authoritative agency knowledge base for AI routing decisions |
| Included in repo | No — embedded directly in Lambda source code as a formatted string constant |

**Description:**
The official 2025–2026 Mississippi State Government Telephone Directory, published by ITS, was used as the sole agency routing knowledge base. Agency names, phone numbers, and service descriptions were extracted from the PDF and formatted as a structured text block embedded in the Lambda `AGENCY_DIRECTORY` constant.

**Limitation:** The directory is hardcoded in Lambda source code. Any changes to agency phone numbers, new agency additions, or organizational changes require a Lambda code deployment to take effect. A production deployment should replace this with a managed knowledge base (e.g., Amazon Kendra) with an ITS-controlled update interface.

---

### 2. DynamoDB Call Logs — its-triage-calls

| Field | Details |
|---|---|
| Source | Generated by the PoC system during testing |
| Format | Amazon DynamoDB (NoSQL) |
| Data type | Synthetic / PoC test calls only |
| Included in repo | No — lives in AWS DynamoDB; not exported |

**Schema:**

| Field | Type | Description |
|---|---|---|
| call_id | String (UUID) | Unique call identifier |
| timestamp | String (ISO 8601) | UTC timestamp of the call |
| caller_input | String | Intent name or text input received from Connect |
| routed_agency | String | Agency name returned by Bedrock |
| phone | String | Agency phone number returned by Bedrock |
| confidence | String | Confidence score (0.0–1.0) as string |
| fallback_to_human | String | "True" or "False" |
| status | String | "success", "human_transfer", "emergency", "error: [message]" |
| verified | String | "null" — reserved for Human-in-the-Loop review |
| correct | String | "null" — reserved for Human-in-the-Loop review |

**PII Note:** The `caller_input` field stores the Lex intent name (e.g., "ChildSupport"), not the raw caller speech. Caller phone numbers were captured in Lambda but are **not** stored in DynamoDB call logs. All test calls were made using the developer's personal phone number. A production deployment would require a privacy review and formal data retention policy before storing any PII.

---

### 3. Amazon Lex Training Utterances

| Field | Details |
|---|---|
| Source | Developed by the student team |
| Format | Managed within Amazon Lex console |
| Data type | Synthetic |
| Included in repo | Documented in `docs/setup.md` intent table |

**Description:**
All Lex training utterances were synthetically generated by the development team. No real ITS call transcripts or citizen speech data were used. The utterances represent reasonable natural language phrasings for each of the 16 intent categories based on the types of calls described in the PoC scope document.

**Limitation:** Intent recognition accuracy on real citizen calls may differ from test results. Real Mississippi callers may use regional dialect, partial sentences, or terminology not represented in the current utterance set. Expanding utterances with real ITS call transcript data (appropriately de-identified) would improve production accuracy.

---

## What Is Not Included in This Repository

- Real citizen call recordings or transcripts
- Production ITS call logs or routing data
- Any PII from ITS systems
- Agency internal contact data beyond the publicly available telephone directory
- Any data from the MISSI chatbot (ms.gov) or other ITS systems

---

## Data Governance Notes

- The Mississippi State Government Telephone Directory is publicly available and published by ITS — no data use agreement is required for the information embedded in this PoC
- All DynamoDB test data was generated exclusively by the development team and does not represent real citizen interactions
- If this system were expanded to production, ITS would need to establish a formal data governance policy covering: call log retention periods, PII handling procedures, access controls on DynamoDB, audit trail requirements, and integration with existing ITS data governance frameworks
- The `verified` and `correct` fields in DynamoDB are reserved for a Human-in-the-Loop review process in which ITS staff would review routing decisions before they are used to improve AI prompt accuracy — this process was designed but not operationalized during the PoC
